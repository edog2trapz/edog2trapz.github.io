# Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | WASD (arrows up/down) | Left thumb stick |
| Look | Mouse (click to lock), arrows left/right | Drag with right thumb |
| Switch item | 1–5, Q, mouse wheel | ITEM |
| Run (loud) | Shift | RUN |
| Hit the stash | Hold Space (tap once for a tab) | Hold TAP |
| Hide / leave stall, vent, flush, exhale | E (or F) | E |
| Punch | F | PUNCH |
| Tricks (while holding a hit) | R O's · G ghost · T French | trick bar |
| Phone | Tab | 📱 |
| Hold actions (hotwire, pickpocket, rob, haircut) | hold E | hold E |
| In class | Space work · hold 1 copy/AI · hold 2 phone AI · 3 cheat sheet | class panel buttons |
| Vehicles | W/S, mouse or A/D to steer, Shift = wheelie | stick + RUN |
| Pause | Esc / P | Pause button |
| Mute | M | ♪ button |
