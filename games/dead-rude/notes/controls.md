# Controls

## Alive (hunter)

| Keyboard and mouse | Touch | Action |
| --- | --- | --- |
| W A S D, Shift, C | left thumb (push all the way to run), DUCK | walk, run, crouch |
| Mouse | right thumb | look |
| E | USE | doors, light switches, fuse box, hiding spots, pickups, tethers, the front door |
| Left click | ITEM | use the tool you are holding |
| 1-6 or mouse wheel | NEXT | switch tool |
| R or right click | SMOKE (hold) | draw on your smoke, release to blow |
| X | | switch smoke |
| T | TAUNT | be rude (through the spirit box if you hold it) |
| F | LIGHT | flashlight |
| J or Tab | J | journal |
| P or Esc | II | pause |

## Dead (ghost)

| Keyboard and mouse | Touch | Action |
| --- | --- | --- |
| Left click | SMACK | slap (in the Veil); three hits make a combo |
| R or right click | PUFF | smoke |
| Q | VEIL | cross into the ghost dimension |
| T or E | ROAST | roast the ghost you are looking at; during its wind-up it is a Counter-Roast |
| Space | DASH | dash, or teleport with Butler's Blink |
| 2 / 3 | BOOKS / WAIL | Scholar's Volley / Bride's Wail |
| F | ME | Main Character Moment when Ego is full |
